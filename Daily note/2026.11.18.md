**Analysis**
- Changing order in a absolutly convergence sequence. For a fixed $n$ , there is $a_{1}$, $a_2$, ... , $a_n$ and therefore we can find large enough $m$ such that $\sigma (i) (i\in [1,m])$ covers all of $1 \text{to} n$, and consider $T_{m} -S_{n}$ so that we are only left with **terms after $n$ .** The so called **tail terms** can be controled with *convergence condition*.
- The general idea is, when there is **two variables**, **fix one** and see what we can get. After that, and think '*what property is needed*', and **impose conditions on the fixed one** such that **the wanted property is satisfied**.

Investigation into *bijectivity*
- In this proof, because $\sigma$ is a *bijective function* from $\mathbb{N} \to \mathbb{N}$, it is natural to consider the question **where is bijectivity used?** or **what does bijectivity prevent?**
- If we get rid of bijectivity, and a number in $\mathbb{N}$, namely $n$ is mapped to *infinite times*, the obviously $a_{n}$ get accumulated in the rearranged sequence, and it diverges. What if such $n$ does not exist. 
- 1. If (stronger) $\exists M s.t \forall n\in N$, $f^{-1}({n}) <M$ then, if we examine the proof, it still holdes. 2. If $\forall n\in N$, $f^{-1}(n)$ is **finite**. Then things gets little bit complicated. **Investigate upon this**

- General idea: Picking a suitable $\epsilon$ at a suitable time is a good trick.
- If $\sum a_{n}$ converges, then $|a_{n}|\to0$ (this can be proved by Cauchy). **Conversely**, if we have $|a_{n}|$ does not tend to $0$, then $\sum a_{n}$ **does not converge**. Generally, if we want to show that $\sum a_{n}$ doesn't converge, we can look at the limit behaviour of $|a_{n}|$.
