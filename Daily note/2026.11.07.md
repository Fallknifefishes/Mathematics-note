## **💡 Insight**
- Subgroups are an **internal structure**, whereas normal subgroups involves communitativity with external elements of the group, and hence is **not internal structure.**
- Foundamental theorem of homomorphism: Let $\phi:G \to H$ were $N \lhd G$, then we have $$
G/\ker\phi \cong \mathrm{Im}(\phi)
$$
- This is essentially because if $x\ker\phi = y\ker\phi$ then $\phi (x) = \phi(y)$
![[Pasted image 20261108062818.png|293]]

- Hom preserves group oporation, therefore if $\phi: G\to H$ is a hom mapping then
	- if $\phi$ is surjective, then $N \lhd G$ $\implies$ $\phi(N) \lhd H$
	- If $K\lhd H$ then $\phi^{-1}(K) \lhd G$
- The above property also hold if we change $\lhd$ to $\leq$

- Proof: The proof is essentially using definition, **Return to definition is the key**, and note that for any function $\phi:A\to B$ and $X \subset A$ and $Y \subset B$   we have $X \subset \phi^{-1}(\phi(X))$ and $\phi(\phi^{-1}(Y)) \subset Y$. The reason of the first one is **non-injectivity** and the second is **non-surjectivity**

- For any hom mapping $\phi:G\to H$ and $N = \ker{G}$, we have a one to one correspondence between subgroups of $G$ containing $N$, and subgroups of $H$.
