## **💡 Insight**
- The understanding about Algebraic limit theorem: It proves both **convergence** and **the limit**, for example $\lim_{  \to \infty } a_{n} = a$ and $\lim_{ n \to \infty } b_{n} = b$ the $\lim_{ n \to \infty }a_{n} + b_{n}$ **exists(So $a_n + b_n$ converges** and is equal to $a+b$. Therefore, if you want to prove something converges, one possible method is to split the 'thing' in to two converging sequence (If it's behaviour is good enough)
- Undertanding about **compact sets**: In general, the uniform continuality of a bounded continues set is only dependent **on the behaviours at limit point**.
	- Let a set A be a bounded (pointwise continues) set, then we can take $\bar{A}$ (the closure of A). **If this is pointwise continues**, then as $\bar{A}$ is compact, it will be uniformly continues on the domain. Since $A\subset \bar{A}$ we conclude that A is uniformly continues.
	- So the key is whether $\bar{A}$ is pointwise continues, and since A is, the only varible is at the limit point . If the limit point is pointwise continues, then A is uniformly continues, if not, the A is not uni continues. Hence, **behaviour at the limit point is what matters**

- BTW, domain is also very importent in **uniform continues** (or in general). If f is UC on D, the f is UC on any (non empty) subset of D.
	- Uniform continues: Preserved when taking subsets
	- UC is a property that is **defined on the basis of the domain**.
