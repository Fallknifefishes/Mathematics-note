## **💡 Insight**
**Probability**
- A probability distribution function can be inspired by, when we take any **outcome space**, it is very *abstract*. So we map the outcome space to a more familar space, namely the reals $\mathbb{R}$, and look at the **probability assigned to each reals**
- Therefore a *joint probability distribution* considers points in $R^n$, and looks at the probability that each point is taken.
- One way of viewing it is through a 3 dimensional graph , with $X_{1}, X_{2}$ as the $x, y$ axis and $P$ has $z$ axis.
- Another is that, we can always convert the probability $P(X=x, Y=y)$ into probability of event space, by finding *preimages*. Namely $$P(X=x, Y=y) = \mathbb{P}(\{\omega_{i}:X(\omega_{i})=x \text{ and } Y(\omega_{i}) = y\})$$

- If we have a *joint distribution*, we can find the individual random varible by *intuitionally* compessing everything . And this is called the **marginal distribution**. Formula-wise, this is just fixing $x_i$ and add $x_j's$ up for every $j\neq i$

**Modelling**
- Dimensional analysis: Intutionally, this **seporates** the dimensions that each term of the model must have, forceing the structure to be d = \[Dimension part\] \[Dimensionless part\]. Therefore we only need to consider about dimensionless part.
