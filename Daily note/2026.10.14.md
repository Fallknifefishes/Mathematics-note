## **💡 Insight**
- Cyclic groups: Groups that is generated by one element $x$. 
- Subgroups of cyclic groups are also cyclic -> proof using bezouts theorem; finding the 'generator'
- The set $\{g, g^{-1}\}$ is very special in for $g$ been an element of a group, as essentially the info it has is 'pressed', knowing one element from this set results to knowing all in the set 
- Partition $|G| = \sum_{A\in P} |A|$ for $P$ beening a partition of $G$. Hence partition gives infomation about the size(or the parity, division arguement) of $|G|$. This is a link **division argument** with **partition**; If we want to proof division arguement of a set, we can find a suitable partition to do so.

- An order relationship on *subsets/groups* are essentially **inclusion relations**
- To proof $x$ is that smallest that satisfies $P$, we proof 1. $x$ satisfies $P$, and $\forall y$ satisfying $P$,  $x\le y$ (**this is a highlight of the proof structure**). The $\le$ here can be a **order relation** such as *subsets* or *subgroups*
