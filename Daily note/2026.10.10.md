## **💡 Insight**
- If f on a A is uniformly continues and A bounded, the f(A) is also bounded. 
  
- The techniques used to prove this argument is very interesting. We take the **closure** of $A$ ($\bar{A}$) try to define $f(l)$ for every $l \in \bar{A} - A$
- In general, $f(l) = \lim_{x_{n} \in A \to l} f(x_{n})$, we need to show this limit exist, and **uniform continues** plays a big role here. (As we can study the counterexample of $\frac{1}{x}$ on $(0, 1)$ which doesn't have a problem continues extendable definition)
- **Uniform continues** says that, give $\epsilon$, for all close enough inputs, the output is closer then epsilon 
- As we want to show $f(l) = \lim_{x_{n} \in A \to l} f(x_{n})$ converges, and we can control $f(x_{n}) - f(x_{m})$ using **uniform continues**, we can use the arguement that it's cauchy. This give a outline and inspiration of the proof

- Summerising, uniform continuesity means **for any close enough output**, we can find **close enough input distances** which holds *globally*.
- Sequency interacting with uniform continues; The stucture promotes **cauchy sequence** $\forall \epsilon >0$, $\exists \delta>0$ such that for all $x, y \in A$, $|x-y|<\delta$  we have $|f(y)-f(x)|< \epsilon$
- So if we have terms in a consequtive converging sequence $x_{n}$, can use $x_n$ is cauchy, and uniform continues to **relate** $x_{n}$ to $f(x_{n})$ and hene see that $f(x_{n})$ is also cauchy.

- Insight: **Limit points**. We can replace limit point with point inside the original set at (basically no) costs - An example of using this property is in the proof of $\bar{A} = \bar{\bar{A}}$

 - Every choice of $(x_n) -> c$, $f(x_n)$ converges is essentially means they converge to the same limit. As we can choose two different $(x_{n})$, $y_n$ and let $z_{2n+1} = x_{n}$ and $z_{2n} = x_{n}$ and $(z_{n})$ also converges to c. So $f(z_n)$ converges, so $f(x_n)$ and $f(y_n)$ converges to the same sequence
