## **💡 Insight**
- A bounded set $A$  an be reduced to a finite number of 'representatives', with every element $a \in A$ a controlled distance from a 'representative'
- Let $X = \{x_{0}, x_{1} \dots x_{n}\}$ for which $inf A= x_0$ and $supA = x_{n}$. For any $\delta$, by Archimedean property, there is a $n$ such that $\frac{supA - infA}{n}<\delta$. Let $x_{k+1} - x_{k} = \frac{supA - infA}{n}<\delta$. So $A = \{V_{\delta}( x_{i})\}$ is a *open cover* of $A$.
- Taking $P = \{p_i\}$ for each $V_{\delta(x_{i})}\cap A \neq \emptyset$ , we take $p_i$ from it, and form the set $P$. Hence for each element $a \in A$, we can find $x_i$ such that $a \in V_{\delta} (x_{i})$ and from there we can find $p_{j} \in V_{\delta}(x_{i})$, $p\in A$. So $|a-p_{j}|< 2\delta$ is **controlled**
- This essentially reduced every element to descrete finite points (Because $A$ is bounded, X is finite set and hence P is also finite)

- Understanding of **boundedness**

- Subgroup  ($H, *$)  of $(G, *)$ is $H \subset G$ and $(H, *)$ is a group.
- This forces $e_{G} \in H$ and inverse of $e_{G}$ in $H$
- **Monoid** doesn't do that, so essentiall, existance of inverse ensures this structure.
