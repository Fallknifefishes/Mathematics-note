## **💡 Insight**
![[Pasted image 20261103061207.png]]

- A group is essentially a set with closed binary oporation that has certain structure
- Group homomorphism: A mapping between group that respect group oporation
- This give certain degree of simplification of information.
- The definition can be interpreated as if we relation $u$ to $h(u)$ and $v$ to $h(v)$. Then $uv$ is related to $h(u)h(v)$ (i.e $h(uv) = h(u)h(v)$ )
- Isomorphism: a group homomorphism that is bijection. Bijectivity means **preservation of information**. So if two groups are isomorphics, they are essentially the same group after relabeling. **As each element in $g\in G$ we can find a unique label $h(g)$, which also uniquely labels $g$.** , and the binary oporation is respected. and for $k, g \in G$, we re-label them to $h(g), h(k)$ we have $h(g) h(k) = h(gk)$ (So essentially the binary oporation is preserved in the re-lable)
- Another way to think about it, is that if two set has a bijection $h$ which *preserved binary oporation*, then the **set are equal(In size)** and the oporation amongst the elements inside the sets are also identical. So they are essentially the same structure, which different element (but the **same interaction of binary oporation on the elements**)
- This may not be the case if not bijective (for example $h(g_{1}) = h(g_{2})$  for two different element $g_1,g_{2}$ inside $G$, hence they are upon the same label)

- For hom mapping $\phi : G \to H$
- $\ker(\phi) = \{x\in G| \phi(x) = e_{H}\}$ and $\ker(\phi) \leq G$
- $\mathrm{Im}(\phi) =\{\phi(x)| x\in G\}$ and $\mathrm{Im}(\phi) \leq H$
