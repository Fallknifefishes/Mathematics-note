## **💡 Insight**
- A discrete  random varible is essentially exist a countable set $S\subset \mathbb{R}$ such that $\mathbb{P}(x\in S) = 1$.
- A Continues random variable requires the existance of a density function $f_{X}$ such that for all **suitable** event $A\in \mathbb{F}$ we have $\mathbb{P}(x\in A) = \int_{A}f_{X}(x) dx$. By definition $\mathbb{P}(X=a) = \int_{a}^{a} f_{X}(x)dx = 0$. $f_{X}(a)$ can be interpreted as '**probability of $a$ if it has unit length**'. So dispite that the point $a$ itself has no probability, it measures the probability contribution $a$ gives for unit length.
