## **💡 Insight**
- Multisets $\{\{\}\}$ is a set, such that **order does not matter**, and the number of times element appears does matter. So $\{\{1, 1, 2, 3\}\}$ is *different from* $\{\{1, 2, 3\}\}$
- Comparing, for a element $x$, the set $\{\}$ essentially assigns $x$ to **1 or 0**. 1 meaning that $x$ appears in the set, and $0$  meaning it doesn't. But a multsets contains way more information, it assignes $x$ a number in $\mathbb{N_{0}}$, the **time** which $x$ appears in the set.
- Talking about this $x$, we need to draw $x$ from a set, call $M = \{1, 2, .., m\}$, and for a multiset $D$ with size $d$ that contains only elements from $M$, we can count the number of such sets
- So this number is $\binom{d+m -1}{m-1}$ , this is essentially **stars and bars**. Because order does not matter, we can assume that inside $D$, elements are arranged in ascending order. The expression $\binom{d+m -1}{m-1}$ counts the way we can put $m-1$ bars on $d+m-1$ stars, creating $m$ intervals seperated by the bars, in which the length of these interval adds up to $d$. This is a valid multiset with size $d$, including elements in $M$. On the otherhand, each valid multiset, arranged in ascending order, we place *bars* in each point of transitioning up by one unit (e.g 111 333... the it is 111 | | 333...), placing in a total of m-1 bars, this results in one of the arrangements of putting $m-1$ bars on $d+m-1$ stars. This is actually a **two way surjection** which implies **bijection**(on finite sets).

- Recall that multisets assignes a $\mathbb{N_{0}}$ to each element. Consider the *dimension of degree d polynomial* with $m$ variables $x_{1}, x_{2}, x_{3} \dots , x_{m}$. (This is case **degree** refers to the amount of distinct degree d monomial that is composed with $x_i's$)
- Each monomial, $x_i$ appears some $\mathbb{N_{0}}$ times (*which is the info encoded by it's power in the monomial*). Overall, the variable appears at the sum of $d$ times *(As they are degree $d$ monomials)*. And the order of appearence **does not matter**. This natually encodes the same information as **a multiset of size $d$, picking it's element from $M$ .** 
- More rigoursly speaking, we can find a **bijection** between degree $d$ monomials with $m$ variables and size $d$ multisets which its elements come from $M$. So they are *equal in amount.*  
- So the **dimension** of $m$ variable polynomials with degree $d$ is $\binom{d+m -1}{m-1}$

- Trick: The **dimension** of $m$ varible polynomials with degree **at most** $d$. So this means the amount of monomials that have degree at most $d$. 
- We introduce a new variable $\omega$, and the key idea is to create a bijection between **m var + at most $d$ .** to *m+1 var + exactly $d$ .* So for any element in set 1, namely $m(x_{i})$ with degree $a$, we can find an element corrisponding to it in set 2, namely $\omega^{d-a}m(x_{i})$. This element in also unique. To say this with more rigour, we can define a function $f: 1 \to 2$ Such that $f(m_{i}) = \omega^{d-deg(m_{i})} m_{i}$ which is bijective. And so, |set 1| = |set 2| and we can count set 2 using above = $\binom{d+m }{m}$

- Reflecting back, it is very common and importent technique to use bijection to map (what we want to count) $\to$ (What we can easily, or have method to count)
