## **💡 Insight**
- Equivalent class = partition = Function 
- And equivalent relationships inside the equivalent class can be viewed as complete graph.

- So any equivalent classes on $S$ is a partition of $S$， $P = \{\bar{t}|t\in S\}$ because $\bar{t_{1}}$ and $\bar{t_{2}}$ are either equal or disjoint, and they go over the whole set $S$
- Partition: $\forall x\in S$ , $\exists !A_{i}$ s. t $x\in A_{i}$, this looks very similar with the definition of a **function**. Essentially, a partition is a function which mappes $S$ to the set of sets $A_{i}$ which forms the partition.
- So equivalent class = partition = function 
- Reversly, one can find a partition of set $S$ from a function, consider $f:A\to B$ is a function, then $\{f^{-1}(\{b\})|b \in \mathrm{Im}(A)\}$ is a partition of the set $A$.

- Any partition, we can let the element in the partition be the **nodes** and form a **complete graph** out of it, the edge is then a *equivalence relation* and hence the partition is an *equivalence class*

- Lagranges theorem: Essentially because $x\in Hy$ is an **equivalence relation** between $x$ and $y$, **(Why is that? What structure garentees that?)**. So $\{t | t \in Hy\} = Hy$ is equivalent class, and hence partition of $G$, $|Hy| = |H|$ and due to *partitions*, $|G| = m|H|$ and thus $|H|$ is a factor of $|G|$
