## **💡 Insight**
The nature of fixed points in classified into stable and unstable. Unstable means that for arbitrary intervals near the fixed point we can find a value which it's iteration falls some finite distance away from y*. Stable means that opposite, for any small distance given near the fixed point, we can fine an interval near y* which all output of the value is inside the given interval

Stability is in essence the **derivative behaviour** of the function at fixed point(Lemma)

One single value which it's iteration converges to the fix point will not imply the fix point is Stable.
